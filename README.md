# 🍁 تراكر غنائم وميسو MapleLand - شركة المرعبين المحدودة

تطبيق ويب مستقل وسريع، مصمم خصيصاً لمتابعة وحساب حصيلة الفارمينج والدروبات لمجموعة الـ 3 لاعبين:
1. **محمد (Mohamed)**
2. **طنط ايمي (Tant Amy)**
3. **عبدالرحمن (Abdelrahman)**
4. **👑 بروفايل المحصلة الكلية (Grand Total Pool):** يعلو كافة البروفايلات لحساب وتجميع كافة العناصر والدخل التراكمي بالميسو للفريق ككل لحظياً!

---

## 🌟 مميزات التراكر
1. **بروفايل المحصلة الكلية في المقدمة:**
   - يجمع تلقائياً ميسو ودروبات الـ 3 أعضاء في شاشة واحدة.
   - يعرض مؤشر نسب المساهمة (Contribution Bars) لكل لاعب في إجمالي الدخل.
   - يعرض جدول مفصل (Collapsible Accordion) يوضح كل عنصر كم يملك منه كل عضو وإجمالي قيمته السوقية.
   - يحدد تلقائياً "المزارع الأكثر تجميعاً حالياً".

2. **بروفايلات فردية مخصصة لكل لاعب:**
   - واجهة مستقلة لكل لاعب بألوان ورموز مميزة.
   - أزرار سريعة للزيادة والنقصان (`+` / `-`) وإدخال مباشر للرقم.
   - أزرار إضافات سريعة فورية (`+5`، `+10`، `+50`، `+100`، `+500`).
   - تصنيف سريع حسب الفئات (قطع شمس وقمر ونجوم، خامات وجواهر، لفائف نادرة، دروبات متنوعة، معدات، كاش ميسو مباشر).
   - بحث فوري باللغتين الكورية والعربية (مثال: بحث عن `가넷` أو `جارنت` أو `شمس`).

3. **حفظ ومزامنة مزدوجة (Local + Free Cloud):**
   - **يعمل فوراً دون أي إعداد:** يحفظ البيانات تلقائياً في ذاكرة المتصفح (`LocalStorage`).
   - **مزامنة جماعية مجانية (Multiplayer Live Sync):** يدعم الربط المباشر مع **Firebase Realtime Database** المجانية حتى يرى محمد وطنط ايمي وعبدالرحمن تعديلات بعضهم لحظياً من أي مكان وجهاز بدون الحاجة لأي سيرفر مدفوع!
   - أزرار تصدير واستيراد احتياطي بصيغة `JSON`.
   - زر نسخ تقرير الفريق بنقرة واحدة لإرساله في الشات / Discord / WhatsApp.

## 🚀 كيفية رفع الموقع على استضافة مجانية (في 30 ثانية)

المشروع عبارة عن **Static HTML / CSS / JS** بالكامل، مما يجعله جاهزاً للعمل مجاناً 100% مدى الحياة على أي منصة استضافة ثابتة:

### الطريقة الأولى: Netlify Drop (الأسهل والأسرع - 30 ثانية بدون كود)
1. افتح موقع: [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. اسحب ملف `MapleLand_Team_Tracker.zip` (أو مجلد `tracker` بالكامل) وأفلته في المربع المخصص بالصفحة.
3. مبروك! سيمنحك Netlify رابط موقعك فوراً (مثل: `https://mapleland-team.netlify.app`).

### الطريقة الثانية: Vercel
1. ادخل على [https://vercel.com](https://vercel.com).
2. اختر "Deploy" أو ارفع مجلد `tracker` عبر GitHub.

### الطريقة الثالثة: GitHub Pages
1. أنشئ مستودعاً جديداً (New Repository) على GitHub باسم `mapleland-tracker`.
2. ارفع ملفات مجلد `tracker` بداخله.
3. ادخل على **Settings** -> **Pages** -> اختر `Branch: main` واضغط **Save**.

## 🔥 كيفية تفعيل قاعدة البيانات السحابية المجانية (Firebase)

إذا أردتم أن يقوم محمد بإدخال دروباته من جهازه فتظهر تلقائياً في نفس اللحظة أمام طنط ايمي وعبدالرحمن:

1. افتح **[Google Firebase Console](https://console.firebase.google.com)** وسجل بحساب جوجل العادي.
2. اضغط **Add Project** (إضافة مشروع) وسمّه مثلاً `mapleland-tracker`.
3. من القائمة الجانبية في اليسار، اضغط على **Build** ثم اختر **Realtime Database**.
4. اضغط **Create Database**، واختر المكان الافتراضي (مثلاً `United States`).
5. في خطوة الأمان، اختر **Start in test mode** (أو توجه لتبويب **Rules** وضع القواعد التالية):
   ```json
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
   ```
6. انسخ رابط قاعدة البيانات من الأعلى، والذي يكون بصيغة:
   `https://your-project-id-default-rtdb.firebaseio.com/`
7. اضغط على أيقونة الترس ⚙️ بجانب Project Overview في أعلى اليسار -> **Project Settings**.
8. ستجد هناك **Web API Key** (مفتاح الـ API).
9. افتح موقع التراكر الخاص بكم، واضغط على زر **🔥 قاعدة البيانات** في الشريط العلوي:
   - الصق رابط قاعدة البيانات في خانة `Database URL`.
   - الصق الـ API Key في خانة `API Key`.
   - اكتب اسم المشروع في `Project ID`.
   - اضغط **حفظ وتفعيل الاتصال**.

🎉 **الآن أصبح التراكر متصلاً سحابياً بنظام Live Sync لجميع أفراد الفريق!**

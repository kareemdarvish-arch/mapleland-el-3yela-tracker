⚙️ بيانات مفتاح اتصال Firebase:

💡 كيف تحصل على هذه البيانات مجاناً 100%؟

  1. ادخل إلى Firebase Console وسجل بحساب جوجل.
  2. أنشئ مشروعاً جديداً مجانياً واضغط على Realtime Database ثم Create Database.
  3. اختر في قواعد الأمان (Rules): السماح بالقراءة والكتابة ".read": true, ".write": true.
  4. انسخ رابط قاعدة البيانات والـ Web API Key والصقهم بالأعلى واضغط حفظ!
